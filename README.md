# ArduinoUploader

Android приложение на Java за зареждане на Intel HEX фърмуер към Arduino Mega 2560 през USB OTG.

## Компилация
- Проектът се компилира автоматично от GitHub Actions при push към `main` или ръчно чрез **Actions → Build ArduinoUploader APK → Run workflow**.
- APK файлът се изтегля от секцията **Artifacts** на успешното изпълнение.
- Минимална версия: Android 10 (API 29). Препоръчва се Android 10 или по-нов с USB Host/OTG.

## Използване
1. Инсталирай APK файла на телефона.
2. Свържи Mega 2560 чрез USB OTG кабел за данни.
3. Натисни **Открий / свържи платката** и разреши USB достъпа.
4. Избери валиден Intel HEX файл.
5. Потвърди записването и не изключвай кабела по време на операцията.

## Ограничения и безопасност
- Реализацията използва STK500v2, очакван при стандартния bootloader на Arduino Mega 2560. Различни клонинги/bootloader-и може да се държат различно.
- Първата версия проверява структурата и контролните суми на Intel HEX, но не прави пълно прочитане и побитово сравнение на Flash след запис.
- Физическата проверка с конкретната платка е задължителна. Не използвай първата версия за критична операция без предварителен тест.
- Не изключвай захранването по време на запис. Ако bootloader-ът е повреден или липсва, ще е нужен външен ISP програматор.
